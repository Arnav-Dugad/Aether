# Contributing

Use Node.js 22.12+ or 24, then `npm ci`. Keep TypeScript strict, URL/import validation intact, incognito filtering explicit, and browser capabilities honestly labeled. Never add fake production analytics or decorative controls without behavior.

Run `npm run check`, install Playwright Chromium, and run `npm run test:e2e`. Confirm light/dark, opaque/high-contrast, narrow layouts, and reduced motion. Use fixtures only in tests. Describe what you actually validated and where native/browser checks remain unavailable.

Keep material changes in the shared CSS tokens. Preserve classic matte frosting and readable content rather than adding lensing or reflective animation. New features should remain useful offline and request optional permissions when invoked.

Update docs/STATUS.md and CHANGELOG.md for feature changes. Package and manifest versions must agree. Never commit signing keys, API credentials, or personal browsing backups.
