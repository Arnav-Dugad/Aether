# Aether premium roadmap

These are proposals, not implemented functionality. Prioritize local-first usefulness, accessible controls, measured performance, and explicit privacy boundaries.

## Browser workflows

1. Tab drag ordering with keyboard alternatives.
2. Workspace rules with preview and reversible assignments.
3. Saved split-view research layouts.
4. Pinned launchpad links with custom icons.
5. Workspace-specific home screens and goals.
6. Session timeline with tags and visual comparison.
7. Recovery checkpoints for interrupted restores.
8. Bookmark folder browsing, editing, and batch cleanup.
9. History date filters and pagination.
10. Command favorites, aliases, and shortcut editing.

## Focus and planning

11. Durable pause/resume with correct duration accounting.
12. Pomodoro sequences with short and long breaks.
13. Opt-in website blocking with clear bypass controls.
14. Ambient sound mixer with locally bundled audio.
15. Recurring tasks and configurable rollover.
16. Priority drag ordering and a weekly planning board.
17. Per-workspace focus goals and session labels.
18. Scheduled focus rituals and optional reminders.
19. Local end-of-day reflection.
20. A weekly local productivity review.

## UI and personalization

21. Resizable/reorderable dashboard with accessible controls.
22. Named appearance presets and per-surface layouts.
23. Local wallpaper imports and palette extraction.
24. Scheduled light/dark themes.
25. Bundled fonts and adjustable type scale.
26. Collapsible navigation rail.
27. Interactive workflow onboarding.
28. Large-target touch mode and side-panel preferences.
29. Custom workspace glyphs and palettes.
30. A separate lightweight popup bundle.

## Analytics and data

31. Custom date ranges and equal elapsed-time comparisons.
32. Workspace-level focus/browsing reports.
33. User-defined website categories.
34. Hourly heatmaps backed by newly recorded timestamped data.
35. Session-length distributions and consistency trends.
36. Recorded tab-count trends, without reconstructing unobserved history.
37. Storage inspector, quota usage, and retention controls.
38. Searchable local automation audit history.
39. Granular restore with preview/conflict resolution.
40. Encrypted portable backups with user-controlled keys.

## Visuals and motion

41. Accessible activity-map day popovers.
42. Workspace treemap of observed activity shares.
43. Interactive session timeline.
44. Focus journey using genuine completed sessions.
45. Shared-layout transitions between tab cards/lists.
46. Drag feedback, drop previews, and spring settling.
47. Optional accessible completion celebrations.
48. Stable loading skeletons and empty-to-loaded transitions.
49. Theme transitions without contrast flashes.
50. Motion intensity settings and pause for ambient loops.

## Reliability and releases

51. Browser-store distribution and signed release provenance.
52. Opt-in update checks with caching/retry backoff.
53. In-app checksum guidance and verification.
54. Accessibility regression matrix across all themes.
55. Tested Edge/Brave/Vivaldi compatibility builds.
56. Separately reported synthetic/native-tab benchmarks.
57. IndexedDB corruption recovery and export rescue.
58. Local background-accounting diagnostics.
59. Optional local AI with explicit model/data consent.
60. Optional encrypted device sync as a separate capability.
